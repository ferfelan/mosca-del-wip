# Security

Español más abajo.

Mosca del WIP is a static site. It has no accounts, no server code and no
database. It uses no cookies, and what you choose in the game stays in your
browser.

## How to report a problem

If you find a security problem in the site or in this code, please do not
open a public issue. Use **Report a vulnerability**, in the Security tab of
this repository. Only the maintainer can read that report.

Say what you found, where, and how to see it. One person keeps this project,
so the answer can take a few days.

## What is in scope

- The pages and files served at https://mosca.deliverycraft.ai
- The code in this repository

Other sites on the same domain are not part of this project.

# Seguridad

Mosca del WIP es un sitio estático. No tiene cuentas, código de servidor ni
base de datos. No usa cookies, y lo que eliges en el juego se queda en tu
navegador.

## Cómo avisar de un problema

Si encuentras un problema de seguridad en el sitio o en este código, por favor
no abras un issue público. Usa **Report a vulnerability**, en la pestaña
Security de este repositorio. Ese aviso lo lee solo quien mantiene el
proyecto.

Cuenta qué encontraste, dónde y cómo verlo. El proyecto lo mantiene una sola
persona, así que la respuesta puede tardar unos días.

## Qué cubre

- Las páginas y los archivos que entrega https://mosca.deliverycraft.ai
- El código de este repositorio

Los otros sitios del mismo dominio no son parte de este proyecto.
